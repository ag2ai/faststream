    Projects using FastStream#

    Below are open-source projects and organizations whose public repositories or published packages declare FastStream as a dependency, together with tools that ship a FastStream integration of their own.

    About this list

    This list is compiled from public repositories and package metadata. Inclusion does not imply endorsement, support, or any affiliation with the FastStream project. If your organization is listed and you would prefer not to be, open an issue and we will remove the entry.

    Community Extensions#

    Packages built on top of FastStream by the community:

    • stompman - STOMP client with a pleasant API
    • faststream-mq - standalone IBM MQ adapter
    • zMQTT - pure asyncio MQTT 3.1.1 and 5.0 client library, no paho dependency
    • faststream-schema-registry - connects FastStream to the Confluent Schema Registry
    • opentelemetry-instrumentation-faststream - FastStream instrumentation for OpenTelemetry
    • faststream-prometheus - metrics collection for Prometheus
    • faststream-compressors - message compression middleware
    • faststream-deadline-propagation - deadline propagation for RPC requests
    • faststream-outbox - transactional outbox backed by a Postgres table
    • faststream-redis-timers - Redis-backed distributed timer scheduling
    • faststream-concurrent-aiokafka - concurrent message processing for aiokafka
    • modern-di-faststream - modern-di integration
    • litestar-faststream - Litestar integration for FastStream message brokers
    • fast-healthchecks - framework-agnostic health checks
    • awesome-faststream - curated list of libraries, tools, templates and resources
